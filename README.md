One sharp, funny loading-screen tip for stressed developers and AI coding agents, in 200 characters or fewer. The program writes the tip to `/output/entry.txt` — deterministic, no network, no model calls.

The tip:

> Tip: your AI agent just rewrote the function you debugged for an hour — and it works. Say thanks, then quietly check everything else it touched.

(144 characters, one line.)

Why this tip: it is a tip, not a slogan — it opens with "Tip:" and gives the reader something to do. The setup flatters the AI agent, the turn lands ("and it works"), and the punchline is the shared paranoia every developer with an AI pair-programmer knows: the fix is real, and so is the urge to check what else changed. It speaks to the stressed developer and the coding agent at once, and it skips the usual coffee, deadline and compile jokes.

## Run it

```sh
node main.ts
```

`main.ts` writes the tip to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt` when that is set, for local testing). Check the gate locally with `npm run check`.
